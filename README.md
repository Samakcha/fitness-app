# Fitness App

A simple and responsive fitness application built to help users explore workouts and maintain a healthy lifestyle. The project focuses on creating an intuitive user interface with a clean design and smooth user experience.

## Features

-  Responsive design
-  Browse workout categories
-  Exercise details
-  Modern and clean UI
-  Fast and lightweight application

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```
fitness-app/
│── assets/
│── css/
│── js/
│── index.html
└── README.md
```

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/Samakcha/fitness-app.git
```

2. Navigate to the project directory

```bash
cd fitness-app
```

3. Open `index.html` in your browser.
